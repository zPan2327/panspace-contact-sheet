# Sheet 骨架的来源

本仓库 Sheet 组件的样式与动效骨架，抽取自我个人站点 panspace.odn.cc 的线上打包产物。站点是 Next.js 静态导出，服务器上既没有原始工程、也没有 source map，所以是从压缩产物里还原出来的。这里记录过程，方便日后维护，或者再抽别的样式。

## 抽取步骤

1. 找到含目标文案的 chunk：`grep -rl 关键词 _next/static/chunks`
2. 压缩代码是单行的，先用 sed 把分号、右花括号替换成换行，落到临时文件
3. 用 `grep -n` 定位行号，再用 `sed -n` 读区间
4. 弹窗样式在线上是写在 JS 里的模板字符串，按行区间原样导出为 sheet.css，未做任何数值改动

## 压缩变量名对照

行号以断行后的临时文件为准（本次是对 chunks 目录下的页面 chunk 操作）。

| 压缩名 | 实际是什么 | 行号 |
| --- | --- | --- |
| sD | Sheet 弹窗组件 | 3521 |
| sR | 弹窗的注入式 CSS 字符串（sheet.css 的来源） | 3206 起 172 行 |
| r2 | Button 按钮组件 | 2861 |
| r0 / r1 | Button 的 variant / size 类名表 | 2858 / 2859 |
| rS | motion 动画库 | - |
| sF | 关闭按钮用的 XIcon | 3205 |

## 与本仓库的差异

- 本仓库只收录 UI 骨架；线上版本里的页面内容（文案、图标、邮件链接等）没有收录
- Button 的类名拼接从模板字符串改成数组 join，行为一致
- Sheet 关闭时增加了定时器清理：原线上版本在关闭动画没结束时再次打开，旧的关闭回调会误关新弹窗
